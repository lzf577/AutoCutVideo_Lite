# AutoCutVideo Lite (v1.05 - 虚晃双音轨混音与阿里镜像极速版)

> **专为体育解说、赛事复盘、知识科普与短视频创作者打造的极简 AI 批量视频流水线合成工具。**  
> 一键拖入文件夹，自动完成 **语音识别 -> AI错别字校对 -> PDF幻灯片语义对齐 -> 虚晃空镜智能切片穿插 -> 4K/1080p 多层GPU极速压制 -> 批量导出成片**。

---

## 🌟 核心特性与架构亮点

1. ⚡ **双引擎高鲁棒性时长与音轨探测**：
   - 内置 `ffprobe` 与 `ffmpeg -i` 双引擎自动降级回退机制；
   - 彻底解决 Windows 环境下的编码冲突，新电脑**免外部环境配置、开箱即用**。
2. 🎙️ **精准语音转写与模型自动下载 (v1.05 全新升级)**：
   - **Faster-Whisper** 本地离线高精度转写（支持 **medium / small / base / large-v3** 等全系列模型）；
   - **国内高速镜像源 (hf-mirror.com) 全自动下载**：本地未下载指定模型时，启动转写自动后台高速拉取，免手动配置；
   - **智能容错与平滑回退**：若网络中断或异常，自动平滑切换至本地已有模型，确保批处理绝不中断。
   - **Gemini 网页版静默校对**（免 API Key / 0 费用）与 **官方 API 接口** 双模式，智能修正专有名词与错别字。
3. 🎞️ **虚晃空镜双音轨完美混音修复 (v1.05 新增)**：
   - 彻底解决切片阶段被 `-an` 强行剥离音频的问题，智能保留原素材音频并转码 AAC 48kHz；
   - 采用 `atrim + adelay + afade` 毫秒级时间戳对齐与平滑淡入淡出；
   - 启用 `amix=normalize=0`，确保人声解说 100% 洪亮贯穿，虚晃背景音真实细腻呈现。
4. 📄 **PDF 幻灯片毫秒级语义时间轴对齐**：
   - PyMuPDF 极速提取高清幻灯片；
   - 本地 **RapidOCR 图文特征分析** 与 **大模型语义分析** 双引擎，自动识别比赛场次与话题转折点，精准上屏。
5. 🎞️ **三维黄金动态排期调度（广播级视听铁律 · 彻底杜绝纯PPT死板霸屏）**：
   - **📄 PDF 课件 (~25%)**：语音讲到对阵双方、机构盘口、风控定性时准时切入，黄金展示约 **8.0 秒**（由 `pdf_slide_duration` 控制），观众获取关键图表数据后自然适时退场；
   - **⚽ 比赛高燃切片 (~34%)**：课件退场后紧随切入进球/对抗/通道入场等赛场集锦（约 **7.5 秒**），单集切片数扩充至 **近 30 个**，赛场动感拉满；
   - **🎬 背景主视频 (~41%)**：在切片与下一张课件之间自然恢复主播面对面动态解说画面（约 **8~14 秒**），主播播客演播室贯穿全片，绝不消失；
   - **长段落动态轮转**：当单幕时长超过 22 秒时，系统自适应实现「**课件(8s) ➔ 切片1(7.5s) ➔ 主视频(6~8s) ➔ 切片2(7.5s) ➔ 主视频(过渡)**」平滑轮转。
6. 🚀 **两阶段极速压制与 GPU 硬件加速**：
   - 自动识别并激活 **Intel QuickSync (QSV)** / **NVIDIA (NVENC)** / **AMD (AMF)** / **CPU (多线程)** 硬件加速；
   - 阶段一（画面层合成） + 阶段二（独立 ASS 高清字幕压制） + 阶段三（独立片头封面帧拼接），画质清晰不卡顿。
6. 🔄 **全流程智能断点续传与缓存复用**：
   - 自动缓存提取音频、字幕文件、AI校对文本、幻灯片图片及空镜头切片；
   - 重复运行或中断恢复时**秒级跳过已完成步骤**；主视频变更时自动刷新缓存。

## 📁 目录约定结构 (方式 A)

只需将每个视频工程按文件夹归类，统一放入批处理根目录：

```text
我的赛事批处理/
├── 第1集/
│   ├── 第1集.mp4          # 主视频（必选，支持与PDF同名/文件夹同名/关键词）
│   ├── 第1集.pdf          # 幻灯片演示（可选，支持任意 .pdf 文件）
│   ├── 1_封面.png         # 项目专属封面（可选，支持 cover/封面/fm 等命名）
│   ├── 1英超.mp4          # 项目专属虚晃素材（可选，支持 空镜/素材/赛事名 等）
│   └── logo女.mp4         # 项目专属Logo水印（可选，支持 logo/水印 图片或视频）
├── 第2集/
│   ├── 第2集.mp4
│   └── 第2集.pdf
├── ...
└── output/                # 最终批量生成的成片导出目录
```

## 🛠️ 快速启动

### 方式一：直接运行源码

1. **安装依赖环境**：
   ```bash
   pip install -r requirements.txt
   ```
2. **启动图形界面**：
   ```bash
   python main.py
   ```
3. 在界面中点击 **“📂 选择目录”** 载入批处理文件夹，点击 **“▶️ 一键开始批量处理”** 即可全自动流转完成！

项目已深度优化 Windows 单文件打包配置，内置优雅退出与动态库释放机制：

## ⚙️ 核心配置文件 (`config.json` / `.env`)

* `enable_llm_polish`: 是否开启大模型字幕智能校对
* `enable_pdf_align`: 是否开启 PDF 幻灯片语义时间轴对齐
* `broll_enable`: 是否开启虚晃空镜头切片穿插
* `video_encoder`: 编码器选择（`auto` 自动探测 / `qsv` / `nvenc` / `amf` / `cpu`）
* `subtitle_preset`: 字幕配色预设（如明黄解说、极简纯白、活力金橙等）
* `trim_start` / `trim_end`: 全局片头/片尾裁剪秒数
